# 레시피 — 이런 앱은 이렇게 만듭니다

넥슨 Open API로 실제로 많이 만드는 앱 유형을 골라, 필요한 조회와 가공 방법을 처음부터 끝까지 정리했습니다. 게임별 전체 기능은 [게임 문서](../maplestory.md)에, 설치와 키 발급은 [시작 가이드](../getting-started.md)에 있습니다.

| 레시피                                                              | 만드는 것                                                                     | 쓰는 도우미                                                          |
| ------------------------------------------------------------------- | ----------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| [메이플스토리 장비 분석 도구](./maplestory-equipment-calculator.md) | 환산 주스탯 계산기, 스펙 비교 사이트처럼 장비 옵션을 모아 계산하는 도구       | `summarizeItemOptions`, `sumItemTotalOptions`, `getItemStarforce` 등 |
| [메이플스토리 코디 카드](./maplestory-coordi-card.md)               | 캐릭터 외형 이미지에 동작·표정을 입히고 캐시 장비, 헤어·성형을 보여 주는 카드 | `characterImageUrl`, `MAPLE_CHARACTER_ACTIONS` 등                    |

## 레시피가 공통으로 지키는 것

- **호출 수를 먼저 셉니다.** 개발 단계 키는 1초에 5건, 하루 1,000건입니다(넥슨 안내, 2026-11-24). 화면 하나에 조회가 몇 번 드는지 세고 캐시를 붙입니다.
- **문자열로 오는 숫자를 바꿔서 계산합니다.** 스타포스(`"22"`), 장비 옵션(`"150"`)은 문자열입니다. 도우미 함수가 숫자로 바꿔 줍니다.
- **모르는 값을 버리지 않습니다.** 게임 업데이트로 새 옵션이 생겨도 도우미는 원문을 그대로 남깁니다.
- **API 키와 캐릭터 고유 번호(OCID)는 서버에만 둡니다.** 웹페이지 코드, 주소, 로그, 파일 이름에 넣지 않습니다.
- **출처를 표기합니다.** 화면에 `Data based on NEXON Open API` 를 적습니다.

실행할 수 있는 완성 파일은 [examples](../../examples/README.md)에 있습니다.
