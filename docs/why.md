# 왜 이 라이브러리인가

"넥슨 API는 주소에 요청만 보내면 되는데, 그냥 `fetch` 로 부르거나 AI에게 짜 달라고 하면 되지 않나요?" 라는 질문에 답하는 문서입니다.

짧게 답하면 이렇습니다. **넥슨 문서대로 짠 코드는 실제 서버에서 여러 군데가 어긋납니다.** 넥슨도 이를 알고 [AI 에이전트 가이드](https://openapi.nexon.com/ko/guide/ai-agent/)에 이렇게 적어 두었습니다.

> 응답 스키마도 실제와 다를 수 있습니다. (…) 파싱 코드를 쓰기 전에 엔드포인트마다 실제 응답 한 건을 스키마와 대조하고, 다른 곳은 실제를 따르세요.

이 라이브러리는 그 대조를 14개 게임에 대해 미리 해 둔 결과물입니다. AI를 대신하는 것이 아니라 **AI와 사람이 함께 쓰는 재료**입니다.

## 같은 일, 두 가지 코드

메이플스토리 캐릭터 카드에 레벨, 무기의 남은 업그레이드 횟수, 펫 장비 이름을 넣는다고 해 봅시다.

### 넥슨 문서만 보고 직접 짠 코드

문법 오류도 없고 넥슨 문서의 필드 이름도 그대로 썼습니다. 그런데 실제 서버에서는 ①~⑥이 어긋납니다. 모두 2026-11-24에 실제 응답으로 확인한 내용입니다.

```js
const BASE = 'https://open.api.nexon.com/maplestory/v1';
const headers = { 'x-nxopen-api-key': process.env.NEXON_API_KEY ?? '' };

async function get(path, params) {
  const res = await fetch(`${BASE}${path}?${new URLSearchParams(params)}`, { headers });
  const body = await res.json();
  // ① 없는 캐릭터 이름에도 넥슨은 "Please input valid parameter" 를 준다.
  //    그대로 보여 주면 방문자는 오타가 아니라 서비스 고장으로 읽는다
  if (!res.ok) throw new Error(body.error.message);
  return body;
}

const { ocid } = await get('/id', { character_name: '캐릭터명' });

// ② 오늘 날짜를 넣으면 400 이 온다. 게다가 이 식은 한국 시간이 아니라 UTC 날짜다
const today = new Date().toISOString().slice(0, 10);
const basic = await get('/character/basic', { ocid, date: today });
console.log(`${basic.character_name} Lv.${basic.character_level}`);

const equip = await get('/character/item-equipment', { ocid });
const weapon = equip.item_equipment.find((item) => item.item_equipment_slot === '무기');
// ③ 문서의 이름은 scroll_upgradable_count, 실제 응답은 scroll_upgradeable_count → undefined
console.log(`남은 업그레이드 ${weapon?.scroll_upgradable_count}`);

// ④ 프리셋 장비의 문서상 이름은 equipment_slot, 실제는 item_equipment_slot → 항상 못 찾는다
const presetWeapon = equip.item_equipment_preset_1.find((item) => item.equipment_slot === '무기');
console.log(`1번 프리셋 무기 ${presetWeapon?.item_name}`);

const pet = await get('/character/pet-equipment', { ocid });
// ⑤ 펫 장비를 안 낀 캐릭터는 item_name 이 null → 내 캐릭터로는 되다가 남의 캐릭터에서 멈춘다
console.log(`펫 장비 ${pet.pet_1_equipment.item_name.trim()}`);

// ⑥ 넥슨은 고유 번호(OCID)를 로그에 그대로 남기지 말라고 안내한다
console.log(`[debug] ocid=${ocid}`);
```

③과 ④가 까다로운 이유는 **에러가 나지 않기 때문**입니다. 화면에 `undefined` 가 찍히거나 값이 빈 채로 넘어갑니다. ⑤는 테스트한 캐릭터가 펫 장비를 끼고 있으면 공개한 뒤에야 드러납니다.

### 이 라이브러리로 짠 코드

```js
import { NexonClient, NexonNotFoundError } from 'nexon-open-api';

const client = new NexonClient({ apiKey: process.env.NEXON_API_KEY ?? '' });

try {
  const ocid = await client.maplestory.getOcid('캐릭터명');

  // 날짜를 생략하면 가장 최근 데이터다
  const basic = await client.maplestory.character.getBasic({ ocid });
  console.log(`${basic.character_name} Lv.${basic.character_level}`);

  const equip = await client.maplestory.character.getItemEquipment({ ocid });
  const weapon = equip.item_equipment.find((item) => item.item_equipment_slot === '무기');
  // 실제 응답의 이름이 자동완성에 나온다
  console.log(`남은 업그레이드 ${weapon?.scroll_upgradeable_count ?? '-'}`);

  const presetWeapon = equip.item_equipment_preset_1.find(
    (item) => item.item_equipment_slot === '무기',
  );
  console.log(`1번 프리셋 무기 ${presetWeapon?.item_name ?? '없음'}`);

  const pet = await client.maplestory.character.getPetEquipment({ ocid });
  // item_name 이 null 일 수 있다고 타입에 적혀 있어, 처리를 빼먹으면 에디터가 알려 준다
  console.log(`펫 장비 ${pet.pet_1_equipment.item_name ?? '없음'}`);
} catch (err) {
  // 없는 캐릭터는 "파라미터 오류"가 아니라 NexonNotFoundError 로 온다
  if (err instanceof NexonNotFoundError) console.log('캐릭터를 찾을 수 없어요.');
  else throw err;
}
```

| 직접 짠 코드에서 어긋난 곳      | 이 라이브러리에서는                                                                             |
| ------------------------------- | ----------------------------------------------------------------------------------------------- |
| ① 없는 캐릭터에 "파라미터 오류" | `NexonNotFoundError` 를 던집니다. 14개 게임의 이름 조회가 모두 같습니다                         |
| ② 오늘 날짜, 시간대             | 날짜를 생략하면 최신입니다. 메이플스토리 계열은 오늘·미래 날짜를 넥슨에 보내기 전에 알려 줍니다 |
| ③ ④ 문서와 다른 필드 이름       | 타입이 실제 응답의 이름을 따릅니다. 틀린 이름은 에디터에서 빨간 줄이 그어집니다                 |
| ⑤ 예상하지 못한 `null`          | 실제로 `null` 이 오는 필드는 타입에 `null` 이 적혀 있습니다                                     |
| ⑥ 로그에 남는 고유 번호         | `debug: true` 의 로그는 고유 번호를 가려서 출력합니다                                           |

메이플스토리만의 일이 아닙니다. 다른 게임에서 확인한 차이도 타입에 반영되어 있습니다.

- **FC 온라인** — 문서의 `OffsideCount` 는 실제로 `offsideCount`, `spId` 는 `spid` 로 옵니다.
- **히트2** — 문서의 `character_last_login` 은 실제로 `character_date_last_login` 으로 옵니다.
- **마비노기 영웅전 랭킹** — 문서에는 목록(배열)이라고 되어 있지만 실제로는 `{ ranking: [...] }` 로 옵니다. 문서대로 `list[0]` 을 읽으면 `undefined` 입니다. 이 라이브러리는 목록으로 풀어서 돌려줍니다.
- **서든어택** — 랭크전 티어는 숫자가 아니라 문자열로 옵니다.

## 넥슨 AI 가이드와 이 라이브러리

넥슨의 [AI 에이전트 가이드](https://openapi.nexon.com/ko/guide/ai-agent/)는 "자동으로 호출할 때 무엇이 어긋나는가"를 정리한 공식 문서입니다. 가이드의 항목마다 이 라이브러리가 하는 일과 **하지 않는 일**을 적었습니다. "창작자 몫"이라고 적힌 항목은 [서비스에 올리기 전 체크리스트](service-checklist.md)에서 다룹니다.

### 반드시 지킬 것

| 넥슨 가이드                                                         | 이 라이브러리가 하는 일                                                                                                                                  | 더 보기                                                       |
| ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| 1. API 키는 서버에만 둔다                                           | 키가 비어 있으면 `new NexonClient()` 에서 바로 알려 줍니다. 키를 어디에 두는지는 **창작자 몫**입니다                                                     | [체크리스트](service-checklist.md#1-api-키는-서버에만-둡니다) |
| 2. 날짜는 필요할 때만 넣고, 필수인 조회에서는 빼지 않는다           | 날짜를 생략하면 최신 데이터를 조회합니다. 메이플스토리 계열은 조회할 수 없는 날짜를 요청 전에 막습니다 ([아래](#날짜-규칙))                              | [FAQ](faq.md#오늘-데이터가-안-나와요--예전-장비가-나와요)     |
| 3. 재시도는 호출량 초과(429)·서버 오류(5xx)·점검에만, 간격을 벌려서 | 429와 5xx만 자동으로 다시 시도합니다. 간격은 시도마다 두 배로 늘리고 무작위 시간을 더해 요청이 몰리지 않게 합니다 ([아래](#에러-처리))                   | [설정 옵션](../README.md#설정-옵션)                           |
| 4. 200을 받아도 핵심 필드가 `null` 인지 확인한다                    | 메이플스토리 계열의 서비스 개시 이전 날짜는 요청 전에 막습니다. 그 밖에 `null` 이 올 수 있는 필드는 타입에 적혀 있어 에디터가 확인을 요구합니다          | [같은 일, 두 가지 코드](#같은-일-두-가지-코드)                |
| 5. 응답을 캐시한다                                                  | **하지 않습니다.** 무엇을 얼마나 저장할지는 서비스마다 달라서 **창작자 몫**입니다                                                                        | [체크리스트](service-checklist.md#4-응답을-저장할-때)         |
| 6. 화면에 출처를 표기한다                                           | **하지 않습니다.** 화면은 **창작자 몫**입니다                                                                                                            | [체크리스트](service-checklist.md#4-응답을-저장할-때)         |
| 7. 저장한 데이터는 30일 이내에 갱신한다                             | **하지 않습니다.** **창작자 몫**입니다                                                                                                                   | [체크리스트](service-checklist.md#4-응답을-저장할-때)         |
| 8. 호출량이 한도 안에 드는지 확인한다                               | 빈 이름이나 잘못된 값처럼 실패할 요청은 보내기 전에 걸러 한도를 아낍니다. 화면 하나에 몇 번 부를지는 **창작자 몫**입니다                                 | [체크리스트](service-checklist.md#3-호출량을-먼저-셉니다)     |
| 9. 필터 값은 정해진 값에서만 고른다                                 | 넥슨은 정해진 값 밖의 필터를 에러 없이 무시하고 전체 결과를 줍니다. 이 라이브러리는 허용값을 자동완성으로 보여 주고, 다른 값은 요청 전에 에러로 알립니다 | [FAQ](faq.md#입력이-잘못됐다고-나와요-nexonbadrequesterror)   |

### 하지 말 것

| 넥슨 가이드                                              | 이 라이브러리가 하는 일                                                                                                                                          | 더 보기                                                                   |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| 1. 고유 번호를 로그·파일명·URL에 그대로 남기지 않는다    | `debug: true` 의 로그는 고유 번호(ocid·ouid·oguild_id)를 가립니다. 직접 남기는 로그에는 `maskIdentifier()` 를 쓸 수 있습니다. 파일명과 URL은 **창작자 몫**입니다 | [체크리스트](service-checklist.md#5-고유-번호를-밖으로-내보내지-않습니다) |
| 2. 다시 보내도 결과가 같은 에러를 재시도하지 않는다      | 없는 대상, 잘못된 입력, 다른 게임의 키 같은 에러는 재시도 없이 바로 던집니다. 한도를 낭비하지 않습니다                                                           | [에러 처리](#에러-처리)                                                   |
| 3. 고유 번호를 받았다고 "찾았습니다"라고 하지 않는다     | 고유 번호로 정보를 조회하다 실패해도 같은 `NexonNotFoundError` 로 옵니다. "찾았습니다"는 정보 조회까지 끝난 뒤에 표시하세요. 표시 시점은 **창작자 몫**입니다     | [FAQ](faq.md#캐릭터를-못-찾아요)                                          |
| 4. 넥슨의 에러 설명을 화면에 그대로 쓰지 않는다          | 상황마다 에러 종류가 달라서, 종류별로 알맞은 문구를 붙일 수 있습니다                                                                                             | [README](../README.md#에러-처리)                                          |
| 5. 표본 범위 없이 집계를 전체 통계처럼 보여 주지 않는다  | **하지 않습니다.** 집계와 표기는 **창작자 몫**입니다                                                                                                             | —                                                                         |
| 6. 한 캐릭터의 순위를 찾으려고 랭킹 페이지를 훑지 않는다 | 메이플스토리 랭킹처럼 넥슨이 지원하는 조회에는 `ocid` 를 넣을 수 있습니다. 넣으면 그 캐릭터의 순위만 옵니다                                                      | [메이플스토리 문서](maplestory.md)                                        |

### 에러 처리

넥슨의 에러 코드를 외울 필요가 없도록 상황별 에러 종류로 나눕니다.

| 넥슨 코드                | 넥슨 가이드의 설명                        | 이 라이브러리                                                                  | 자동 재시도 |
| ------------------------ | ----------------------------------------- | ------------------------------------------------------------------------------ | ----------- |
| `OPENAPI00001`, HTTP 5xx | 서버 내부 오류                            | `NexonServerError`                                                             | 예          |
| `OPENAPI00002`           | 권한 없음                                 | `NexonAuthError`                                                               | 아니오      |
| `OPENAPI00003`           | 유효하지 않은 고유 번호                   | `NexonNotFoundError`                                                           | 아니오      |
| `OPENAPI00004`           | 파라미터 누락, **또는 대상 없음**         | 이름 조회에서는 `NexonNotFoundError`, 그 밖에는 `NexonBadRequestError`         | 아니오      |
| `OPENAPI00005`           | 유효하지 않은 API 키                      | `NexonAuthError`                                                               | 아니오      |
| `OPENAPI00006`           | 키에 등록되지 않은 게임이거나 잘못된 경로 | `NexonAuthError`. 어느 게임의 키가 필요한지 메시지에 게임 이름으로 알려 줍니다 | 아니오      |
| `OPENAPI00007`, HTTP 429 | 호출량 초과                               | `NexonRateLimitError`                                                          | 예          |
| `OPENAPI00009`           | 데이터 준비 중                            | `NexonDataNotReadyError`                                                       | 아니오      |
| `OPENAPI00010`           | 게임 점검 중                              | `NexonMaintenanceError`                                                        | 아니오      |
| `OPENAPI00011`           | API 점검 중                               | `NexonMaintenanceError`                                                        | 예          |

- 가이드는 데이터 준비 중(`OPENAPI00009`)과 게임 점검 중(`OPENAPI00010`)도 재시도할 수 있다고 적습니다. 이 라이브러리는 이 둘을 **자동으로 재시도하지 않습니다.** 점검은 몇 초 안에 끝나지 않고, 데이터 준비 중은 날짜를 잘못 넣었을 때도 오기 때문입니다. 에러를 받아 "점검 중이에요", "아직 데이터가 없어요"라고 안내하는 편이 낫습니다.
- `OPENAPI00006` 은 가이드가 "가장 자주 걸리는 지점"으로 꼽은 코드입니다. 메이플스토리 키로 FC 온라인을 조회하면 이 코드가 오는데, 넥슨의 설명만 보면 주소를 잘못 쓴 것처럼 읽힙니다.

### 날짜 규칙

| 넥슨 가이드                                                                     | 이 라이브러리가 하는 일                                                                                      |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 날짜가 선택인 조회에 오늘·미래 날짜를 넣으면 400 "파라미터 오류"가 온다         | 메이플스토리 계열(KMS·SEA·Taiwan·M)은 요청 전에 막고, 어떤 날짜부터 조회할 수 있는지 알려 줍니다             |
| 서비스 개시 이전 날짜는 에러 없이 200이 오고, 날짜 외의 모든 필드가 `null` 이다 | 메이플스토리 계열은 요청 전에 막습니다. 빈 값을 정상 응답으로 저장하는 일이 없습니다                         |
| 랭킹처럼 날짜가 필수인 조회는 오늘 날짜를 받는다. 미래와 범위 밖 날짜는 에러다  | 랭킹은 미래와 범위 밖 날짜만 막습니다                                                                        |
| '오늘'은 서버 시각이 아니라 그 게임의 기준 시간대로 센다                        | `toNexonDate(date, 540)` 으로 기준 시간대의 날짜를 만듭니다 (메이플스토리는 한국 시간, SEA·Taiwan은 UTC+8)   |
| 그날 데이터가 열리는 시각은 조회마다 다르다                                     | 넥슨이 안내한 시각을 게임 문서와 [FAQ](faq.md#오늘-데이터가-안-나와요--예전-장비가-나와요)에 옮겨 두었습니다 |

메이플스토리 계열이 아닌 게임의 날짜 입력은 달력에 있는 날짜인지만 확인합니다. 그 게임에서 실제로 조회되는 범위는 직접 확인해야 합니다.

### 고유 번호(식별자)

| 넥슨 가이드                                                 | 이 라이브러리가 하는 일                                                                                                                          |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 고유 번호에는 API 키와 같은 계정에 묶인 값이 들어갈 수 있다 | 디버그 로그에서 고유 번호를 가립니다. `maskIdentifier()`·`maskIdentifiers()` 로 직접 남기는 로그도 가릴 수 있습니다                              |
| 고유 번호는 바뀔 수 있다. 오래 저장하지 않는다              | 저장해 둔 번호로 조회가 안 되면 `NexonNotFoundError` 가 납니다. 이름으로 다시 받으세요. 저장과 갱신은 **창작자 몫**입니다                        |
| 고유 번호 파라미터의 이름이 게임마다 다르다                 | 게임마다 `getOcid()`·`getOuid()` 로 받아 그대로 넘기면 됩니다. TypeScript에서는 전용 타입이라 다른 문자열을 실수로 넣으면 에디터가 알려 줍니다   |
| 고유 번호를 웹페이지로 내려보내지 않는다                    | **하지 않습니다.** 웹페이지에 무엇을 내려 줄지는 **창작자 몫**입니다 ([체크리스트](service-checklist.md#5-고유-번호를-밖으로-내보내지-않습니다)) |

### 이 라이브러리가 하지 않는 것

정리하면 아래는 직접 챙겨야 합니다. [서비스에 올리기 전 체크리스트](service-checklist.md)에 하나씩 풀어 두었습니다.

- 응답 캐시와, 저장한 데이터의 30일 이내 갱신
- 화면의 출처 표기 ("Data based on NEXON Open API")
- 화면 하나에 드는 호출량 계산
- 고유 번호를 URL·파일명·웹페이지에 내보내지 않는 일
- 집계 화면의 표본 범위 표기

## AI와 함께 쓰기

AI가 넥슨 API 코드를 짤 때 틀리는 곳은 사람이 틀리는 곳과 같습니다. AI도 넥슨 문서를 보고 짜기 때문입니다. [위의 직접 짠 코드](#넥슨-문서만-보고-직접-짠-코드)는 문서만 본 AI가 내놓을 법한 코드이기도 합니다.

그래서 AI에게 맡길 때 이렇게 요청하면 됩니다.

> nexon-open-api 라이브러리로 메이플스토리 캐릭터 카드를 만들어 줘.

AI는 라이브러리의 타입에 적힌 **검증된 필드 이름**과 에러 종류를 그대로 씁니다. 틀린 필드 이름을 쓰면 타입 검사에서 바로 걸리므로 AI가 스스로 고칠 수도 있습니다.

AI 코딩 도구에 이 라이브러리를 알려 주는 방법은 [AI와 함께 쓰기](ai-guide.md)에 있습니다.

## 다른 라이브러리와 비교

2026-11-24에 조회한 내용입니다. 각 프로젝트는 계속 바뀌므로 최신 상태는 직접 확인해 주세요.

|              | nexon-open-api (이 라이브러리)                | [maplestory-openapi](https://www.npmjs.com/package/maplestory-openapi) | nexon_openapi (Python)     |
| ------------ | --------------------------------------------- | ---------------------------------------------------------------------- | -------------------------- |
| 다루는 게임  | 14개 게임과 Open API 공지                     | 메이플스토리 (KMS·MSEA·TMS)                                            | 여러 게임                  |
| 언어         | JavaScript·TypeScript                         | JavaScript·TypeScript, Python, Java, C#                                | Python                     |
| 의존성 (npm) | 없음                                          | axios, dayjs, xml2js                                                   | —                          |
| 사용 현황    | —                                             | npm 월 690회, GitHub 별 40개                                           | 2024-07 이후 업데이트 없음 |
| 확인 방법    | 실제 서버 응답과 263개 조회 대조 (2026-11-24) | 해당 프로젝트 문서 참고                                                | 해당 프로젝트 문서 참고    |

- **메이플스토리만 다루고 Python·Java·C#이 필요하다면 maplestory-openapi가 좋은 선택입니다.** 네 가지 언어를 지원하고 npm에서 한 달에 690회 내려받는 라이브러리입니다. 이 라이브러리는 JavaScript·TypeScript만 지원합니다.
- **이 라이브러리가 맞는 경우**는 이렇습니다.
  - 메이플스토리 말고 다른 게임도 다룬다. FC 온라인 전적, 마비노기 경매장, 서든어택 전적을 같은 사용법으로 조회합니다.
  - 문서가 아니라 실제 응답에 맞춘 타입이 필요하다.
  - 설치할 것을 줄이고 싶다. 다른 패키지를 함께 설치하지 않습니다.
- 메이플스토리 전용 커뮤니티 MCP 서버도 2개 있습니다. AI와 대화하면서 캐릭터를 조회하는 용도라면 그쪽이 맞고, 내 봇이나 사이트의 코드를 짜는 용도라면 라이브러리가 맞습니다.

## 실서버 검증 내용

**무엇을 했나** — 2026-11-24에 게임별 개발 단계 키로, 게임마다 직업·레벨·월드가 다른 공개 캐릭터 2~6명(모두 42명)을 조회했습니다. 조회 267개 중 263개의 응답을 타입과 안쪽 필드까지 비교했습니다.

**무엇이 나왔나** — 처음에는 127개 조회에서 600종이 넘는 차이가 나왔습니다. 문서에 없는 `null`, 이름이 다른 필드, 숫자와 문자열의 차이, 목록과 객체의 차이입니다. 모두 실제 응답에 맞춰 차이 0건이 됐습니다. 없는 캐릭터 이름에 넥슨이 "파라미터 오류"(`OPENAPI00004`)를 주는 것도 14개 게임 모두에서 확인했습니다.

**부르지 못한 4개**

- FC 온라인 이적시장 거래 기록 `getTradeList` — 키를 발급한 계정 본인의 기록만 나옵니다.
- 메이플스토리 `getLegacyOuid` — 구 개발자센터 키가 필요합니다.
- FC 온라인 `getAllMatchList` — 넥슨이 제공을 끝냈습니다.
- FC 온라인 `getSeasonIdMeta` — 키 없이 열리는 파일이라 따로 확인했습니다.

**한계** — 캐릭터마다 가진 데이터가 달라서, 처음 보는 장비·펫·스킬 구성에서는 또 다른 `null` 이 나올 수 있습니다. 넥슨이 응답을 바꿀 수도 있습니다. 응답이 타입과 다르면 [이슈](https://github.com/Kimhasa/nexon-open-api-sdk/issues)로 알려 주세요 ([FAQ](faq.md#응답이-실제-게임과-달라요)).

같은 확인을 직접 다시 해 보는 방법은 [CONTRIBUTING.md](../CONTRIBUTING.md#실서버-확인)에 있습니다.
