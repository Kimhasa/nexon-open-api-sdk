# AI 코딩 도구 사용 안내

Claude, ChatGPT, Cursor, GitHub Copilot 등으로 봇이나 사이트를 만들 때 `nexon-open-api`의 참고 자료를 제공하는 방법을 안내합니다.

## 라이브러리 참고 자료를 제공하는 이유

AI 코딩 도구는 NEXON Open API 포털의 OpenAPI 스펙을 참고할 수 있습니다. 2026년 11월 24일 게임별 API Key로 공개 캐릭터 42명을 표본으로 263개 API의 실제 응답을 대조하여 600종이 넘는 차이를 확인했습니다. 아래 표는 실제 응답과 스펙이 다른 사례입니다.

| 스펙을 참고한 코드                                                  | 실제 응답 및 결과                                                                       |
| ------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 장비의 업그레이드 가능 횟수를 `scroll_upgradable_count`로 읽습니다. | 실제 필드는 `scroll_upgradeable_count`이므로 `undefined`가 반환됩니다.                  |
| 없는 캐릭터를 조회하면 "찾을 수 없음" 에러가 반환된다고 가정합니다. | 넥슨은 "파라미터 오류"(`OPENAPI00004`)를 반환합니다. 봇은 "잘못된 요청"으로 안내합니다. |
| 마비노기 영웅전 랭킹 응답을 배열로 처리합니다.                      | 응답은 `{ ranking: [...] }` 객체이므로 `list[0]`이 비어 있습니다.                       |
| 펫 장비의 이름 필드에 바로 접근합니다.                              | 장착하지 않은 칸은 `null`이므로 처리하지 않으면 화면에 에러가 발생합니다.               |

넥슨은 [AI 에이전트 가이드](https://openapi.nexon.com/ko/guide/ai-agent/)에서 API별 실제 응답을 확인하도록 안내합니다. 이 라이브러리는 실제 응답과 대조한 메서드와 필드 이름, 에러 처리를 제공하므로 AI 코딩 도구에서 참고할 수 있습니다. 더 자세한 비교는 [라이브러리 기능 및 비교](./why.md)에 있습니다.

## 1. AI가 읽을 안내 파일

| 파일            | 내용                                                                                            | 어디서                                                                                                                                      |
| --------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `llms.txt`      | 짧은 소개와 문서 목록                                                                           | [GitHub](https://github.com/Kimhasa/nexon-open-api-sdk/blob/main/llms.txt)                                                                  |
| `llms-full.txt` | 코드 생성 규칙과 14개 게임 및 NEXON Open API 공지의 공개 메서드 목록(시그니처와 게임 용어 설명) | 설치 후 `node_modules/nexon-open-api/llms-full.txt`, 또는 `https://raw.githubusercontent.com/Kimhasa/nexon-open-api-sdk/main/llms-full.txt` |

`llms-full.txt`는 SDK 소스에서 자동으로 만들어지므로 설치한 버전의 메서드 이름과 항상 일치합니다.

## 2. 프로젝트에 지침 추가하기

AI 코딩 도구는 프로젝트의 지침 파일을 참고합니다. 다음 내용을 사용하는 도구의 지침 파일에 추가해 주세요.

| 도구           | 붙여 넣을 곳                      |
| -------------- | --------------------------------- |
| Claude Code    | 프로젝트 폴더의 `CLAUDE.md`       |
| Cursor         | `.cursor/rules/nexon.md`          |
| GitHub Copilot | `.github/copilot-instructions.md` |
| 그 밖의 도구   | 대화 맨 처음에 붙여 넣기          |

```markdown
## 넥슨 게임 데이터

- 넥슨 게임 데이터는 `nexon-open-api` 패키지로 조회합니다. `open.api.nexon.com`에 직접 요청하지 않습니다.
- 사용법과 메서드 목록은 `node_modules/nexon-open-api/llms-full.txt`를 먼저 읽습니다. 필드 이름은 타입을 참고합니다.
- API Key는 게임별로 발급됩니다. `.env`의 `NEXON_<게임>_API_KEY`를 서버에서만 읽습니다.
- 조회는 이름 → 식별자(ocid·ouid) → 정보 순서로 진행합니다. 식별자는 화면·URL·로그에 원문으로 남기지 않습니다.
- 최신 데이터는 `date`를 생략합니다. 오늘이나 미래 날짜는 지정하지 않습니다.
- 에러는 `instanceof`로 구분합니다. 캐릭터 없음은 `NexonNotFoundError`, 점검은 `NexonMaintenanceError`, API Key 오류는 `NexonAuthError`, 호출량 초과는 `NexonRateLimitError`로 처리합니다.
- 결과를 캐시하고 화면에 "Data based on NEXON Open API"를 표시합니다.
```

## 3. 요청 예시

만들고 싶은 것을 게임 용어로 말하고, 라이브러리와 안내 파일을 같이 알려 줍니다.

**디스코드 봇**

> nexon-open-api 패키지로 디스코드 봇의 `!정보 캐릭터명` 명령에 답하는 함수를 만들어 줘. 메이플스토리 캐릭터의 레벨, 직업, 월드, 길드, 전투력, 유니온 레벨을 한 메시지로 보여 주고, 없는 캐릭터·점검 중·호출 한도일 때는 다른 문구를 보여 줘. 사용법은 node_modules/nexon-open-api/llms-full.txt 를 따라.

**랭킹 페이지**

> nexon-open-api 로 메이플스토리 어제 기준 종합 랭킹 TOP 10을 표로 출력해 줘. 월드는 스카니아로 거르고, 한 번 받은 결과는 1시간 캐시해 줘.

**장비 분석 도구 (환산 계산기 재료)**

> nexon-open-api 로 캐릭터의 장착 장비를 받아서 스타포스, 잠재능력, 에디셔널 잠재능력, 추가옵션을 장비별로 정리하고 주스탯 % 합계를 계산해 줘. 옵션 문자열은 "STR +12%" 형식이야.

**경매장 시세**

> nexon-open-api 로 마비노기 경매장에서 아이템 이름으로 매물을 최대 3페이지까지 모아 개당 최저가와 평균가를 알려 줘. 다음 페이지는 next_cursor 로 넘겨.

## 4. 생성된 코드 점검표

생성된 코드를 실행하기 전에 다음 항목을 확인해 주세요. 기준에 맞지 않는 항목은 AI 코딩 도구에 수정을 요청합니다.

- [ ] API 호출에 `nexon-open-api`를 사용합니다.
- [ ] API Key를 `.env`에서 읽습니다. 브라우저 코드에 API Key를 포함하지 않습니다.
- [ ] 여러 게임을 조회할 때는 게임별 API Key와 `NexonClient`를 사용합니다.
- [ ] 최신 데이터를 조회할 때는 `date`를 생략합니다. 오늘 날짜는 지정하지 않습니다.
- [ ] 없는 캐릭터(`NexonNotFoundError`), 점검(`NexonMaintenanceError`), 호출 허용량(`NexonRateLimitError`)를 나눠 안내한다
- [ ] `| null` 인 필드를 확인하고 쓴다
- [ ] 식별자(ocid·ouid)를 화면·URL·로그에 원문으로 남기지 않습니다.
- [ ] 같은 조회를 반복하지 않도록 캐시합니다. 개발 단계의 1일 호출 허용량은 1,000건입니다.
- [ ] 화면에 "Data based on NEXON Open API"를 표시합니다.

## 5. NEXON Open API AI 에이전트 가이드와의 관계

[NEXON Open API AI 에이전트 가이드](https://openapi.nexon.com/ko/guide/ai-agent/)는 API를 직접 호출할 때 확인할 사항을 안내합니다. 라이브러리의 적용 범위는 [라이브러리 기능 및 비교](./why.md)의 대응표에 있습니다. 서비스로 공개하기 전에는 [서비스 공개 체크리스트](./service-checklist.md)도 확인해 주세요.
